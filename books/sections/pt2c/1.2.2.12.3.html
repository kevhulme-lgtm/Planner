1.2.2.12.3 FIND THE ARITHMETIC MEAN OF BASIC GROUPED DATA.

Ungrouped Data:

  1. In all the previous examples, the data has consisted of individual values that do not take into consideration different groups within the data set. This simple data is called ‘ungrouped’ data, and it allows the mean (average) to be calculated easily.

Grouped Data:

  1. When dealing with a large number of observations it is often useful to group them into classes or categories. The number of items which belong to each class can be determined, in order to obtain the class frequency.

If the data is grouped, the Mean and Median can only be estimated.

Finding the Mean of grouped data.

  1. Grouped data is data that has been collected into groups of values, as opposed to specific or individual values. If a frequency table shows grouped data, there is not enough information to calculate the sum of values, so only an estimated value for the mean can be found.

  1. The formula above was fine for ungrouped data. However, when dealing with grouped data, the midpoint of each group must be found and multiplied by the frequency.

SUMMARY

  1. Find the Midpoint of each group and multiply that by the Frequency.
  2. Add the ‘Midpoint × Frequency’ values for each group together to find the ‘Total Midpoint × Frequency’.
  3. Divide ‘Total Midpoint × Frequency’ by the ‘Total of the Frequencies’ to find the mean.
