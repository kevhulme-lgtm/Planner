y = x2 + 4x + 3

Notice from the graph below that the value of y along the x axis is zero:

Fig 3

Substituting y for zero gives: x2 + 4x + 3 = 0

After factorising, the above quadratic equation becomes:

(x + 1) (x + 3) = 0

As the brackets are multiplied together, either one, or both brackets must have a value of zero to produce a solution of zero.

I.e. x + 1 = 0 so (0) (x + 3) = 0

Or

x + 3 = 0 so (x + 1) (0) = 0

These 2 equations can be solved by rearranging them to find the value for x.

x + 1 = 0 therefore x = -1

–

Or

x + 3 = 0 therefore x = -3

–

x = -3 and x = -1 are the roots of the equation (when the function crosses the x axis) and they are shown on the graph above.
