1.2.2.11.1
Data types
1.2.2.11.1 EXPLAIN THE DIFFERENT TYPES OF DATA (DISCRETE, CONTINUOUS, PRIMARY, SECONDARY, QUALITATIVE, QUANTITATIVE).

  1. Before trying to solve problems using statistical data, it is important to be familiar with the terminology.

Terminology

  • A Statistic is a numerical fact relating to collected and classified data.
  • Statistics is the science of classifying and interoperating numerical information.
  • Data (plural) are the information which is obtained during a statistical investigation.
  • Variables – something that can change from one item to the next is called a variable. For example: the colour of the cars in a car park (qualitative variable – non-numerical) or the height of the trees in a park (quantitative variable – numerical). There are two types of numerical or quantitative variable:
  • Continuous. A continuous variable can take any value within a given range. For example: the height of children playing in a game of football. Note: Continuous variables are rounded off to a certain degree of accuracy. E.g., 1.83 m. Things that can be measured.
  • Discrete. A discrete variable increases in whole numbers. For example: The number of aircraft in a hangar, the number of students in a class, or the number of cars on a car park. Things that can be counted.
  • Population – The term population refers to everything in the category under investigation. For example, the people who work in an office block, or the number of cars on the road in the UK.
  • Central Tendency is a single value that describes the way in which a group of data cluster around a central value. To put in other words, it is a way to describe the centre of a data set.
  • Dispersion (Also called variability, spread or scatter) is the extent to which a distribution is stretched or squeezed. Common examples of measures of statistical dispersion are the variance, standard deviation.
  • Range is calculated by subtracting the lowest number from the highest number in a data set. The range can be a useful tool for identifying the spread of the data, but it has limited use in statistics, because it only considers the difference between the maximum and minimum values, and it ignores the distribution of values within the data set.

Types of Data

  • Qualitative data - data that can only be written in words, not numbers, for example, feedback on a hotel booking.
  • Quantitative data - data that can be written in numbers, for example, the proportion of the UK population that has been vaccinated.
  • Primary data - data that have been collected from the original source for a specific purpose, for example, if a Station wanted to know what their junior ranks thought of the mess service, they would question them directly.
  • Secondary data - data that are not originally collected by a group for a specific purpose, for example, finding out the average cost of cars in a car park by using national statistics
