The Outlying Case

  1. In some data sets, extreme values can influence the mean. These are called outliers.

For example: Find the mean age of the students on a course, where one of the students has re-joined and re-mustered into the trade:

19, 22, 17, 18, 21, 17, 43

Place the age values in size order: 17, 17, 18, 19, 21, 22, 43

The mode is 17 and the median is 19. However, the mean age is 23.

  1. Notice that all of the students apart from the outlier are younger than 23, so the outlier has skewed the data.
  2. The decision at this point is whether or not to remove the outlier from the data. If this scenario was an exception, which would never normally happen, then it is safe to remove it from the data. However, if there is a chance of this happening on subsequent courses, then this data value must remain as part of the data set.

Summary

  1. The Mean, Median and Mode are useful measures of central tendency for different kinds of data, but it is important to select the right measure for your purpose.

Mean:

  • A good average because all of the data is used in the calculation.
  • It can be heavily affected by extreme values / outliers.
  • It can only be used with numerical data (i.e., numbers).

Median:

  • The Median is NOT affected by extreme values, so this is a good average to use when there are outliers.

Mode:

  • A shoe shop will order more of the most common sizes.
  • The Mode can be used even with non-numerical data.
  • Some data sets can have more than one mode.
