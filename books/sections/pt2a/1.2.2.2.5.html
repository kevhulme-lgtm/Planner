Simultaneous equations
1.2.2.2.5 SOLVE SIMULTANEOUS EQUATIONS USING ALGEBRAIC METHODS.

  1. Solving Simultaneous Equations means finding the answers to two equations at the same time. Finding values for two unknowns, which in turn make both equations true.

Consider the equations:

        1. y = 3x + 2
        2. y = 2x + 3

These linear equations can be represented on a graph, as shown below:

(1 , 5)

y = 2x + 3

y = 3x + 2

Fig 5

  1. Both equations are in the form y = mx + c, where m is the gradient of the line, and c is the point at which the line crosses the y axis. This point is called the y-intercept.
  2. Notice that the equation y = 3x + 2 has a gradient of 3 and the line crosses the y axis at 2. Similarly, the equation y = 2x + 3 has a gradient of 2 and the line crosses the y axis at 3.
  3. The point at which the lines cross has x and y coordinates (1, 5). This is the solution to the two equations. A quicker and easier way to find this solution is to use algebra.

SIMULTANEOUS SOLUTION TO LINEAR EQUATIONS:

Example 1

Consider the equations from the graph above:

  1. y = 3x + 2
  2. y = 2x + 3

As both of the expressions are equal to y, then they must be equal to each other. In this form the expressions can be equated by substituting one of them for y, as follows:

3x + 2 = 2x + 3

Leave the largest positive coefficient of the variable x in place and manipulate the other terms

3x – 2x = 3 – 2

x = 1

Substitute the value of x into any of the initial equations:

y = 3x + 2

y = 3(1) + 2

y = 5

So, the solution is: x = 1 and y = 5

This is called the substitution method.

The equations can be tested by substituting the x and y values back in.

  1. 5 = 3(1) + 2 so 5 = 5 
  2. 5 = 2(1) + 3 so 5 = 5 

Example 2

Similarly, consider the equations:

  1. y = 5x – 3
  2. y = 4x + 2

As both of the expressions are equal to y, then they must be equal to each other. In this form the expressions can be equated by substituting one of them for y as follows:

5x – 3 = 4x + 2

Leave the largest positive coefficient of the variable x in place and manipulate the other terms

5x – 4x = 2 + 3

x = 5

Substitute the value of x into any of the initial equations:

y = 5x – 3

y = 5(5) – 3

y = 22

So, the solution is: x = 5 and y = 22

This again is the substitution method.

The equations can be tested by substituting the x and y values back in.

  1. 22 = 5(5) – 3 so 22 = 22 
  2. 22 = 4(5) + 2 so 22 = 22 

SUBSTITUTION METHOD

  1. The substitution method is often a simpler solution when the equations are more complex:
  2. x2 + y2 = 25
  3. –x + 2y = 5

Rearrange the linear equation, so that either x or y is on its own on one side of the equation.

–x + 2y = 5

2y – 5 = x so x = 2y – 5

Substitute this expression into the quadratic equation:

x2 + y2 = 25

(2y – 5)2 + y2 = 25

Expand the bracket by multiplying out:

(2y – 5) (2y – 5) + y2 = 25

4y2 – 20y + 25 + y2 = 25

Now gather like terms and rearrange this into the format of ax2 + bx + c = 0.

5y2 – 20y + 25 – 25 = 0

5y2 – 20y = 0

Factorise the equation for y:

5y (y – 4) = 0

Equate each of the factors to zero:

5y = 0 and y – 4 = 0

Therefore: y = 0 and y = 4

Finally place both the values back into the linear equation to find the corresponding values of x.

Linear equation: – x + 2y = 5

When y = 0, – x + 2(0) = 5

– x = 5

x = – 5

When y = 4, – x + 2(4) = 5

– x + 8 = 5

– x = 5 – 8

– x = – 3

x = 3

So, the solutions to the simultaneous equations are:

x = – 5, when y = 0 and x = 3, when y = 4

RECAP

  1. When solving a simultaneous quadratic and linear equation:
  2. Rearrange the linear equation to get either x or y on its own
  3. Substitute the linear equation into quadratic equation to get a quadratic equation in just one variable
  4. Solve to get values for one variable, either by factorising or using the quadratic formula
  5. Place these values into the linear equation to find the corresponding values for the other variable

LOGARITHMS

  1. Logarithms provide a method to solve equations involving exponents or powers.

Definition:

A logarithm is the power to which a base must be raised to produce an ordinary number.

I.e., N = bx Number = base (b) raised to power x.

For equations of the form: N = b x, taking the logarithm of both sides enables a value to be found for x.
