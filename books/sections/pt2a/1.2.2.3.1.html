1.2.2.3.1 CONVERT INDICIAL EQUATIONS BETWEEN INDEX FORM AND LOGARITHMIC FORM.

  1. A logarithm is the power to which a base must be raised to produce a number.

I.e., N = bx (This equation is in index form)

Number = base (b) raised to power x.

Number = 100

Base = 10

power = 2

For example:

100 = 102

In words, 100 = 10 raised to the power 2.

Log is short for Logarithm.

This means that the log to base 10 of the number 100 = 2

Using logarithmic notation, 100 = 102 becomes log10 100 = 2

CONVERTING FROM INDEX FORM TO LOGARITHMIC FORM

The index becomes the number

Example: 16 = 24 can be expressed in logarithmic form as log216 = 4

The 2 becomes the base of the log

Log base 2 of 16 = 4

THE LOGARITHM OF ANY NUMBER THAT IS THE SAME AS ITS BASE

  1. Using the rule: If logb N = x then N = bx, consider the case when log 2 2 = x

To what power must base 2 be raised to give the number 2?

I.e., If log 2 2 = x then 2 = 2x

The power must be 1. So, it follows that the logarithm of any number that is the same as its base will always be 1.

log 10 10 = x then 10 = 10x x = 1

log 3 3 = x then 3 = 3x x = 1

THE LOGARITHM OF THE NUMBER 1

  1. Using the rule: If logb N = x then N = bx, consider the case when log b 1 = x

To what power must any base be raised to give the number 1?

I.e., If log 2 1 = x then 1 = 2x

The power must be zero. So, the logarithm of 1 will always be 0.

(Recall from the laws of indices that anything raised to power zero is 1).

So, log 2 1 = 0

FRACTIONS IN LOGARITHMS

  1. Using the rule: If logb N = x then N = bx, consider the case when log 4 2 = x

To what power must base 4 be raised to give the number 2?

I.e., If log 4 2 = x then x = 41/2

The power must be a fraction.

(Recall from the laws of indices that: x1/2 is the same as √ x)

SUMMARY

  • If N = bx, then logb N = x
  • Logarithms are only defined for positive numbers.
  • Logaa = 1
  • Loga1 = 0
  • Logs can have any base, but base 10 (common logs) and base e (natural logs) are used most often.

  • If no base is stated with the word Log, it will always be base 10.
  • The functions log10 and loge are on your calculator
